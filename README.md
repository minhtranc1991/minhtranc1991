## 3D-Graph

A 3D graph view for Obsidian that sorts a large vault into layers. Built for knowledge graphs of 1,000+ notes, where the core Graph view collapses into a hairball and no graph view separates notes by layer.

<div align="center">
<a href="https://github.com/minhtranc1991/3d-graph-obsidian"><img src="https://raw.githubusercontent.com/minhtranc1991/3d-graph-obsidian/main/docs/images/layers-view.png" alt="3D-Graph: a vault drawn as a tower of layers" width="640"></a>
</div>

[Explore 3D-Graph →](https://github.com/minhtranc1991/3d-graph-obsidian) · [Latest release](https://github.com/minhtranc1991/3d-graph-obsidian/releases/latest) · [README in Vietnamese](https://github.com/minhtranc1991/3d-graph-obsidian/blob/main/README.vi.md)

| | |
|---|---|
| Layers view | Notes stacked as floors of a tower by their `layer` / `type` frontmatter: source, concept, model, strategy, person, framework, case-study, tag, other |
| 3D camera | Drag to rotate; spins like a globe and pauses under the pointer |
| Same look as the core Graph view | Color groups from `graph.json`, no glow or effects |
| Active-note highlight | The open note, its linked notes and the links between them in purple, every linked note labeled |
| Demo vault | One note per layer, to try it in a few minutes |

Plain JavaScript, no runtime dependencies, desktop only, MIT license.
